This is a plain markdown file with YAML frontmatter, sitting in `vault/`.
It's the source of truth — open it in any text editor, put it in git, sync
it however you like.

The SQLite database in `.pkm/index.sqlite` is just a search cache built from
files like this one. Delete it any time and hit **Reindex** to rebuild it.

Ready to look around? Open [[tutorial|the Tutorial]] — it's written *in* the
app, using the app's own features, so reading it is also your first tour.
