## Appears in

A `​```query` block (like the Chapters list on the Book template) only matches a property that's a *single* value — a scene usually has several characters in it at once, so a query block can't reliably list "every scene {{title}} is in." Use a **rollup column** in Table view instead (see [[tutorial/writing-books-and-scripts|Writing books & scripts]]): switch to Table, filter to `type: scene`, add a rollup on the `characters` property, and every scene listing {{title}} shows up automatically — that's what rollups are actually built for.
